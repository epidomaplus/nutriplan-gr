# NutriPlan GR

Διαιτολογικό γραφείο σε μία εφαρμογή: πελάτες, φύλλο παρακολούθησης, ενεργειακές ανάγκες, εβδομαδιαία διαιτολόγια με **ισοδύναμα**, συνταγές, ραντεβού και απλή πύλη πελάτη.

Practice app for dietitians: clients, monitoring sheet, energy estimates, weekly meal plans with **food exchanges**, recipes, appointments and a light client portal.

Οι διατροφικές τιμές και τα ισοδύναμα είναι **εκπαιδευτικές προσεγγίσεις** (τάξη μεγέθους δημόσιων πινάκων). Δεν αποτελούν ιατρική συμβουλή ούτε κλινικό πρωτόκολλο.

## Εκτέλεση / Run

```bash
npm install
npm start
```

Άνοιγμα: [http://localhost:3000](http://localhost:3000) · υγεία: `/healthz`

Πρώτη φορά: «Νέος λογαριασμός». Ο λογαριασμός είναι email + κωδικός, χωρίς δέσιμο σε συγκεκριμένο άνθρωπο.

Προαιρετικά δοκιμαστικά δεδομένα:

```bash
SEED_DEMO=true npm start
```

Διαιτολόγος `demo@example.com` / `demo-pass-1` · πελάτης `client@example.com` / `demo-pass-1`. Κλείστε το `SEED_DEMO` σε κανονική χρήση· οι κωδικοί είναι δημόσιοι.

```bash
npm run smoke
```

## Τι περιλαμβάνει / What is included

- Πελάτες: στοιχεία, ετικέτες, στόχος, αλλεργίες, σημάνσεις (vegan, νηστεία, keto, φόρτιση υδατανθράκων), τιμή συνεδρίας. Κάρτες και πίνακας, φίλτρο ετικέτας.
- Φύλλο παρακολούθησης σε 7 ενότητες (σωματομετρικά, δερματοπτυχές, μεζούρες, βιταμίνες, γενική αίματος, βιοχημικές, ορμόνες), σημειώσεις συνεδρίας, γραφήματα βάρους / λίπους / μυϊκής μάζας, εκτύπωση.
- Mifflin–St Jeor και αναθεωρημένη Harris–Benedict, συντελεστής δραστηριότητας, TDEE, πρωτεΐνη g/kg, υδατάνθρακες %, λίπος ως υπόλοιπο. Ο στόχος kcal μπαίνει σε νέο διαιτολόγιο.
- Εβδομαδιαίο πλάνο, 5 γεύματα (προσθαφαίρεση), αναζήτηση ~240 τροφίμων, σύνολα γεύματος / ημέρας / εβδομάδας.
- Προβολή **Μακροθρεπτικά | Ισοδύναμα | Και τα δύο**. Ομάδες: άμυλο, φρούτο, γάλα, λαχανικά, κρέας άπαχο / μέτριο / παχύ, λίπος, ελεύθερα. Ισοδύναμο υδατανθράκων = g CHO ÷ 15. Προαιρετικός στόχος ομάδων ανά ημέρα.
- Ανάλυση ημέρας (και μικροθρεπτικά Na, ίνες, Ca, Fe, βιτ. C, βιτ. D — κατά προσέγγιση), αντιγραφή ημέρας, πρότυπα γεύματος και εβδομάδας με κλιμάκωση προς τον στόχο kcal, λίστα αγορών.
- Ήπια φίλτρα vegan / νηστεία / keto.
- Συνταγές με αυτόματα σύνολα, εκτυπώσιμη ετικέτα, εισαγωγή στο γεύμα ως μία γραμμή.
- Ραντεβού σε μηνιαίο ημερολόγιο, κατάσταση, κόστος, εισπράξεις / ακυρώσεις.
- Εργασίες με προθεσμία.
- Εκτύπωση πλάνου, ανάλυσης, λίστας, μετρήσεων, ετικέτας. Απόκρυψη μακροθρεπτικών / γραμμαρίων / ισοδυνάμων. Θέμα μεγάλης γραμματοσειράς. Προαιρετικό λογότυπο με URL.
- Πύλη πελάτη με κωδικό ή σύνδεσμο πρόσκλησης (χωρίς αποστολή email): πλάνο, ημερολόγιο κειμένου, ποτήρια νερού, μηνύματα.
- Ελληνικό UI, ανοιχτό/σκούρο θέμα, PWA, `/healthz`.
- Εξαγωγή / εισαγωγή JSON (αντίβαρο στο προσωρινό δίσκο).
- Σελίδα «Βιβλιοθήκη» με τον ορισμό των ισοδυνάμων που χρησιμοποιεί η εφαρμογή.
- Σελίδα «Εργαλεία»: BMI ενηλίκων (WHO), παιδιατρικά όρια Cole 2–18 ετών, Cockcroft–Gault, δείκτης TyG, φυτικές ίνες (ADA 14 g/1.000 kcal και DRI). Εκτιμήσεις επαγγελματία, όχι διάγνωση.

## Μεταβλητές / Environment

| Μεταβλητή | Προεπιλογή | |
|---|---|---|
| `PORT` | `3000` | Θύρα |
| `SESSION_SECRET` | τιμή ανάπτυξης | **Υποχρεωτικό σε production** |
| `ALLOW_SIGNUP` | `true` | `false` κλείνει νέους διαιτολόγους. Ο πρώτος λογαριασμός επιτρέπεται πάντα. Η πρόσκληση πελάτη δεν επηρεάζεται. |
| `DATA_DIR` | `./data` | Φάκελος του `db.json` |
| `APP_NAME` | `NutriPlan GR` | Όνομα στο UI |
| `SEED_DEMO` | άδειο | `true` δημιουργεί δοκιμαστικό γραφείο μόνο αν δεν υπάρχει διαιτολόγος |
| `DEMO_EMAIL` / `DEMO_PASSWORD` | `demo@example.com` / `demo-pass-1` | Μόνο με `SEED_DEMO` |
| `DEMO_CLIENT_EMAIL` | `client@example.com` | Πύλη του δοκιμαστικού πελάτη |

Αποθήκευση: ένα αρχείο JSON. Δεν χρειάζεται βάση. Κατάλληλο για δωρεάν Render, με τον κίνδυνο που περιγράφεται παρακάτω.

## Render

1. Νέο Blueprint από το repo (διαβάζει το `render.yaml`) ή Web Service: build `npm ci --omit=dev`, start `node server.js`, health `/healthz`.
2. Το `SESSION_SECRET` γεννιέται από το blueprint. Μετά την εγγραφή σας, βάλτε `ALLOW_SIGNUP=false` αν το γραφείο πρέπει να μείνει κλειστό.
3. Μην αφήνετε `SEED_DEMO=true` σε δημόσια διεύθυνση.

**Δίσκος.** Στο δωρεάν πλάνο ο δίσκος είναι προσωρινός: το `data/db.json` χάνεται σε redeploy ή restart. Κρατήστε αντίγραφο από «Λογαριασμός → Λήψη JSON».

Για μόνιμα δεδομένα, σε πληρωμένο instance προσθέστε Persistent Disk (π.χ. mount `/var/data`) και `DATA_DIR=/var/data`. Το δωρεάν blueprint δεν δηλώνει δίσκο, για να σηκώνεται χωρίς χρέωση.

## Μεταβίβαση λογαριασμού / Ownership

Δεν υπάρχει προσωπικό email μέσα στον κώδικα. Για να αλλάξει κάτοχος:

1. «Λογαριασμός»: νέο email και, αν χρειάζεται, νέος κωδικός (ζητείται ο τρέχων).
2. Μεταβίβαση του Git repo και του service στο Render, ή νέο deploy από το ίδιο repo.
3. Αντίγραφο JSON πριν από κάθε μεταφορά, και εισαγωγή μετά αν αλλάξει δίσκος.

Οι πελάτες της πύλης συνδέονται με τον διαιτολόγο· δεν γίνονται διαχειριστές.

## Ισοδύναμα

- 1 ισοδύναμο υδατανθράκων = 15 g υδατανθράκων (όλων των ομάδων μαζί).
- Άμυλο και φρούτο: 15 g CHO. Γάλα: 12 g CHO. Λαχανικά: 5 g CHO. Κρέας: 7 g πρωτεΐνης (άπαχο / μέτριο / παχύ από το λίπος της μερίδας). Λίπος: 5 g. Ελεύθερα: χωρίς μερίδα λίστας.
- Όσπρια: 1 άμυλο + 1 άπαχο ανά ισοδύναμο αμύλου (όχι το χούμους ούτε ο αρακάς).
- Η κατάταξη προκύπτει από τη σύσταση του τροφίμου, όχι από αντιγραφή πίνακα τρίτου.
